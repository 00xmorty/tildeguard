# Security policy

Supported version: 0.1.x.

Use GitHub's private vulnerability reporting when available. If unavailable, open an issue containing only a minimal synthetic reproduction and ask for a private channel before disclosing sensitive details. Never post real PATH values, credentials, private paths or logs.

The tool does not evaluate PATH entries, run discovered commands, or change shell settings. Treat repair commands from any source as untrusted and review them manually. A report is not a PATH security audit.
